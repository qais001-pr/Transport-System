# 🚀 Quick Start Guide

Get your Van Pooling Management System running in 3 minutes!

## Step 1: Install Dependencies (1 min)

```bash
npm install
```

## Step 2: Start Development Server (30 seconds)

```bash
npm run dev
```

## Step 3: Open Browser (30 seconds)

Navigate to: **http://localhost:3000**

---

## 🎯 What to Explore

### 1. Landing Page
**URL**: `http://localhost:3000`
- Beautiful hero section
- Feature showcase
- How it works
- Testimonials
- Call-to-action

### 2. Authentication
**Login**: `http://localhost:3000/login`
**Register**: `http://localhost:3000/register`
- Choose your role (Parent, Driver, Admin, Guard)
- Modern form design
- Social login options

### 3. Dashboards

#### Parent Dashboard
**URL**: `http://localhost:3000/dashboard/parent`
- View children status
- Track vans in real-time
- Manage bookings

**Track Van**: `http://localhost:3000/dashboard/parent/track`
- Live GPS tracking
- Route progress
- Driver information

**Find Vans**: `http://localhost:3000/dashboard/parent/vans`
- Search and filter vans
- Girls-Only filter
- Book seats

#### Driver Dashboard
**URL**: `http://localhost:3000/dashboard/driver`
- Today's routes
- Student management
- Earnings tracking
- Quick delay reporting

#### Admin Dashboard
**URL**: `http://localhost:3000/dashboard/admin`
- User management
- Driver verification
- Complaint handling
- System analytics

#### School Guard Dashboard
**URL**: `http://localhost:3000/dashboard/guard`
- Monitor vans
- Verify students
- Track arrivals

## 🐛 Issues?

### Port 3000 in use?
```bash
npm run dev -- -p 3001
```

### Dependencies error?
```bash
rm -rf node_modules package-lock.json
npm install
```

### TypeScript errors?
```bash
npx tsc --noEmit
```
